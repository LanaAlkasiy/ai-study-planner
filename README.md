# AI Study Planner
A Python-based study planner that generates optimized and personalized schedules based on exam dates and topic difficulty.

## Features
- Creates structured study plans from user inputs
- Prioritizes difficult subjects and upcoming exams
- Helps optimize time allocation and productivity

## Technologies
- Python

## How it works
The program takes exam dates and topic difficulty as input, then generates a balanced study schedule to help students prepare efficiently.
